2. Hosting und Serverbetrieb

Diese Website wird auf einem virtuellen Server (VPS) betrieben, der von Oracle Cloud Infrastructure (OCI) bereitgestellt wird.

Der Serverstandort befindet sich innerhalb der Europäischen Union (Frankfurt (EU)).

Beim Aufruf der Website werden durch den Server automatisch sogenannte Server-Logfiles erfasst. Diese können insbesondere folgende Daten enthalten:

  • IP-Adresse (oder gekürzt/anonymisiert)
  • Datum und Uhrzeit des Zugriffs
  • Aufgerufene URL
  • HTTP-Statuscode
  • User-Agent (Browser/Endgerät)

Die Verarbeitung der Logdaten erfolgt ausschließlich zur Sicherstellung des technischen Betriebs, zur Fehleranalyse sowie zur Abwehr von Missbrauch (z. B. Angriffe auf die Infrastruktur).

Rechtsgrundlage: Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an einem sicheren und stabilen Betrieb der Website)

Speicherdauer: Server-Logdaten werden für maximal 14 Tage gespeichert und anschließend gelöscht.

Oracle verarbeitet personenbezogene Daten ausschließlich im Rahmen einer Auftragsverarbeitung gemäß Art. 28 DSGVO.

2a. Nutzung von Cloudflare

Zur Absicherung der Website und zur Bereitstellung einer verschlüsselten HTTPS-Verbindung wird der Dienst Cloudflare (Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA) eingesetzt.

Cloudflare fungiert als Reverse Proxy und stellt Sicherheits- sowie Optimierungsfunktionen bereit. Dabei verarbeitet Cloudflare insbesondere technische Verbindungsdaten (z. B. IP-Adresse), die für die sichere Bereitstellung der Website erforderlich sind.

Cloudflare ist nach dem EU-U.S. Data Privacy Framework, dem UK Extension to the EU-U.S. Data Privacy Framework sowie dem Swiss-U.S. Data Privacy Framework zertifiziert.

Die Übermittlung personenbezogener Daten in die USA erfolgt auf Grundlage des Angemessenheitsbeschlusses der Europäischen Kommission gemäß Art. 45 DSGVO.

Rechtsgrundlage: Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an Sicherheit, Stabilität und verschlüsselter Übertragung)

Weitere Informationen zur Datenverarbeitung durch Cloudflare finden sich in der Datenschutzerklärung von Cloudflare: https://www.cloudflare.com/privacypolicy/

3. Verwendung von Cookies

Diese Website verwendet ausschließlich technisch notwendige Cookies.

Owner-Token-Cookie

Zur Bereitstellung personalisierter Inhalte wird ein Cookie (owner_token) verwendet. Dieses Cookie dient ausschließlich der Zugriffskontrolle und Zuordnung von Dashboards zu einem bestimmten Nutzer.

  • Das Cookie enthält keine Klarnamen oder Kontaktdaten
  • Das Cookie ist technisch erforderlich
  • Das Cookie ist nicht zu Tracking- oder Marketingzwecken bestimmt
  • Das Cookie ist als HttpOnly gesetzt

Rechtsgrundlage: Art. 6 Abs. 1 lit. b DSGVO (Bereitstellung der Funktionalität der Website)

Speicherdauer: Das Cookie bleibt gespeichert, bis es vom Nutzer gelöscht wird oder der Zugriffstoken serverseitig ungültig gemacht wird.

4. Verarbeitung von Nutzungsdaten / Dashboards

Im Rahmen der Nutzung der Website können in einer Datenbank nutzerbezogene Inhalte (z. B. Dashboards oder Konfigurationen) gespeichert werden.

Die Zuordnung erfolgt ausschließlich über einen pseudonymen Zugriffstoken. Es werden keine Benutzerkonten mit Namen, E-Mail-Adressen oder Passwörtern angelegt.

Rechtsgrundlage: Art. 6 Abs. 1 lit. b DSGVO

Speicherdauer: Die Daten werden gespeichert, solange sie für die Nutzung der Website erforderlich sind oder bis sie vom Nutzer gelöscht werden.
